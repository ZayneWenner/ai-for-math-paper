## 二、本地编译（必须做一步）
本机当前**没有**安装 LaTeX，请在装有 TeX Live / MiKTeX 的电脑上执行：

```bash
pdflatex paper
bibtex paper
pdflatex paper
pdflatex paper
```

或在 VS Code（LaTeX Workshop）、Overleaf 中直接打开 `paper.tex` 编译。
所用宏包均为标准包（`article, inputenc, amsmath, amssymb, booktabs, url, hyperref`），任意完整 TeX 发行版都自带，**无需额外安装**。

> 已做静态校验：所有 `\cite` 键存在于 bib、所有 `\label`/`\ref` 闭合、括号平衡，均通过。

## 三、提交前必做
1. 把 `paper.tex` 里的
   ```
   \author{Author Name\\ Affiliation / Institution\\ \texttt{email@example.edu}}
   ```
   换成你的真实姓名 / 学校 / 邮箱（挑战作者为贾静文）。
2. 通读全文，重点确认：
   - 第 7 节的外部数值（20.9%→39.3%、26.5%、51.2%/26.3%、77.9%→89.1% 等）与你引用的原文一致；
   - "语义规约层是瓶颈"是本文**论点**而非公认结论，表述边界无误。
3. 如需投具体会议，可换用对应模板（如 `acl_natbib` / `neurips_2024` 等），但当前版本已满足"可投稿、可编译"基本要求。
